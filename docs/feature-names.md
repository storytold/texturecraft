# Feature names

## Custom GLSL shaders

On 2026-11-28, the new wording was checked against descriptive shader usage in
three unrelated products: [Godot's Shaders documentation](https://docs.godotengine.org/en/stable/tutorials/shaders/index.html),
[Unity's Custom shaders documentation](https://docs.unity3d.com/Manual/Shaders.html)
and [Blender's Shader Nodes documentation](https://docs.blender.org/manual/en/latest/render/shader_nodes/index.html).
The controls use ordinary action and data names such as **Import shader** and
**Search shaders**; GLSL identifies the supported language, as permitted by
the naming standard. **Banded** describes our example shader's lighting.
Names supplied by imported user documents remain document data.

No trademark-register clearance is claimed. Register searches were not
completed in this environment; this departs from the standard's SHOULD check.
The decision is to use descriptive wording and the accurate language name,
with no product or distinctive feature name used for the new controls.

## Generator picker

The picker uses **Worn Metal Edges** for metal edge wear, **Exposed Glass Fibers**
for exposed fibers in a worn coating, and **Rust Runoff** for rust that streaks
along a selected mesh axis. The labels describe the rendered patterns.
Commands, saved generator kinds, and searches using former labels remain
compatible.

On 2026-11-25, the three names were compared with the published generator
documentation and Adobe's trademark list. None appeared in that list. Exact
phrase software searches found no matching generator. The USPTO and WIPO search
interfaces did not expose searchable results in this review environment.

- [Adobe's published trademark list](https://www.adobe.com/cc-shared/assets/pdf/legal/documents/adobe-trademark-database-external.pdf)
- [Painter generator documentation](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/effects/generators/dripping-rust)
- [Designer fiberglass wear documentation](https://experienceleague.adobe.com/en/docs/substance-3d-designer/using/substance-graphs/nodes-reference-for-substance-graphs/node-library/mesh-based-generators/mask-generators/fiber-glass-edge-wear)
