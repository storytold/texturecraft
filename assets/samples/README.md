# Sample projects

Projects that ship with desktop TextureCraft and are offered by File > Open Sample Project.

- `Material Ball.tcraft`: the material ball with smart materials on both texture sets, generated by
  TextureCraft's own `sample_session` (1024 px textures, mesh maps baked at 256 px to keep the file small).

The app embeds these files and copies any missing sample into the `Samples` folder under the data
folder when the entry is used. A file that is already there is never overwritten.
